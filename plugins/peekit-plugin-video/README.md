# 🎬 Pro Video Player & Trimmer (`com.peekit.video-player`)

Профессиональный плагин быстрого предпросмотра, покадровой инспекции и быстрой нарезки видеофайлов для **PeekIt**.

## Возможности

- **Покадровый просмотр**: Точный шаг на 1 кадр назад/вперёд (клавиши `,` и `.` или кнопки на панели).
- **Вырезание фрагментов (Trimming)**:
  - Разметка точек начала `[I]` и конца `[O]` на таймлайне.
  - Экспорт фрагмента в видеоклип (`.webm` / `.mp4`).
  - Экспорт фрагмента в анимированную GIF-анимацию (`.gif`).
- **Снимок кадра в буфер (Full-res Snapshot 📷)**:
  - Захват текущего кадра в исходном нативном разрешении в буфер обмена (`Ctrl+C` / `C`) или файл PNG.
- **Интерактивный Pan & Zoom**:
  - Масштабирование колёсиком мыши (до 500%).
  - Панорамирование перетаскиванием мыши при увеличении.
  - Двойной клик для сброса масштаба.
- **Поворот видео**: на 90°, 180°, 270° (клавиша `R`).
- **Усиление громкости (Volume Boost 200%)**: усиление тихого звука через Web Audio API.
- **A-B Loop**: зацикливание выделенного фрагмента или всего видео.
- **Управление скоростью**: от 0.25x до 3.0x с сохранением тональности звука.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Воспроизведение / Пауза |
| `←` / `→` | Перемотка назад / вперёд на 5 секунд |
| `Shift + ←` / `Shift + →` или `,` / `.` | Шаг на 1 кадр назад / вперёд |
| `I` | Установить начало фрагмента (In) |
| `O` | Установить конец фрагмента (Out) |
| `C` или `Ctrl + C` | Снимок текущего кадра в буфер обмена |
| `R` | Поворот видео на 90 градусов |
| `M` | Отключить / включить звук |
| `[` / `]` | Замедлить / ускорить воспроизведение |
| `F` | Полноэкранный режим |
| `Колёсико мыши` | Масштабирование (Pan & Zoom) |
| `Двойной клик` | Сброс зума / полноэкранный режим |
