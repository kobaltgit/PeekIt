## 1. Контекст и цели задачи

В текущей версии PeekIt (1.2.0) выявлены две проблемы пользовательского интерфейса при работе с плагинами:
1. **Залипающий спиннер (BUG-001):** При переходе на вкладку «Плагины» в настройках бесконечно вращается индикатор загрузки до тех пор, пока пользователь вручную не переключится на вкладку «Магазин плагинов».
2. **Отсутствие реактивности при установке/удалении (BUG-002):** При установке плагина из магазина кнопка «Установить» не меняется на «Установлено» в реальном времени. Аналогично, при удалении плагина список не обновляется моментально. Изменения видны только после закрытия и повторного открытия окна.

Кроме того, требуется расширить функционал приложения:
3. **Поддержка превью содержимого папок (FEAT-001):** Внедрение возможности для плагинов перехватывать и визуализировать содержимое каталогов (файлы, размеры, даты, структура) при нажатии Пробела на папке в Проводнике.
4. **Релиз 1.3.0 и локальная сборка (REL-001):** Обновление версий проекта, создание встроенного легковесного плагина `Folder Viewer` и локальная сборка всех дистрибутивов (NSIS Setup EXE, MSI и Portable ZIP).

## 2. Архитектурный анализ проблем и решений

### А. Причина бага со спиннером и кнопками (Реактивность Svelte)
* Хранилище `pluginRegistry` ([`src/lib/stores/plugins.svelte.ts`](file:///d:/Projects/active/PeekIt/src/lib/stores/plugins.svelte.ts)) использует руны Svelte 5 (`$state`).
* Компонент настроек [`PluginsTab.svelte`](file:///d:/Projects/active/PeekIt/src/lib/components/settings/PluginsTab.svelte) написан в legacy-синтаксисе Svelte 4 (`export let`, `$:`, `on:click`).
* В legacy-режиме компилятор Svelte отслеживает изменения **только локальных переменных** самого компонента. Мутации свойств внешнего класса `pluginRegistry.isLoading` и `pluginRegistry.plugins` не триггерят цикл реактивности (tick) в `PluginsTab.svelte`.
* **Решение:**
  - Ввести в `PluginsTab.svelte` явное локальное реактивное состояние (`installedPlugins`, `isLoadingPlugins`), которое гарантированно обновляется при вызовах `loadPlugins()`, `installPluginPackage()`, `installPluginFromUrl()` и `uninstallPlugin()`.
  - Устранить конфликтный фоновый таймер `setInterval(..., 1500)`, который создавал лишнюю нагрузку на диск и бэкенд каждые 1.5 секунды.
  - Синхронизировать перерисовку статусов каталога сразу после успешной установки или удаления.

### Б. Архитектура поддержки просмотра папок
1. **Rust-бэкенд:**
   - В [`preview.rs`](file:///d:/Projects/active/PeekIt/src-tauri/src/preview.rs) функция `inspect_file`:
     - Проверяет `if path.is_dir()`.
     - Присваивает `category = "folder"`, `extension = "<folder>"`.
     - Считывает поверхностную статистику в `extra` (количество вложенных файлов и папок, общий размер первого уровня).
   - В [`commands.rs`](file:///d:/Projects/active/PeekIt/src-tauri/src/commands.rs):
     - Добавляется команда `read_folder_entries(path: String) -> Result<Vec<FolderItem>, String>`.
     - Чтение строго поверхностное (non-recursive), с безопасным лимитом (до 1000 элементов) и перехватом `PermissionDenied` для защиты от зависаний на системных папках или огромных каталогах (`node_modules`, `WinSxS`).
2. **Манифест и сопоставление плагинов:**
   - В [`manifest.rs`](file:///d:/Projects/active/PeekIt/src-tauri/src/plugins/manifest.rs): разрешить специальный токен `"<folder>"` в списке `extensions` без добавления ведущей точки (`.<folder>`).
   - В [`plugins.svelte.ts`](file:///d:/Projects/active/PeekIt/src/lib/stores/plugins.svelte.ts): поддержать выбор плагина для папок при `category === 'folder'` или `extension === '<folder>'`.
3. **Плагин `Folder Viewer` (`com.peekit.folder-viewer`):**
   - Полностью локальный легковесный плагин (Vanilla HTML/CSS/JS, 0 сторонних зависимостей, ~20 КБ).
   - Интерактивный список/таблица элементов: имя, иконка типа, размер, дата изменения.
   - Поиск/фильтрация на лету при вводе текста.
   - Сортировка по колонкам (имя, размер, дата).
   - Двойной клик для открытия элемента в Проводнике/ассоциированном приложении.
4. **Фронтенд хост:**
   - В [`src/routes/+page.svelte`](file:///d:/Projects/active/PeekIt/src/routes/+page.svelte): если выбран объект с `category === 'folder'`, и для папок зарегистрирован активный плагин — открывать `PluginHost`. Если плагин отключен — отображать аккуратную карточку свойств папки (fallback).

## 4. План локальной сборки (Build & Packaging)

1. **Проверка чистоты кода:**
   - `npm run check` (проверка типов TypeScript и Svelte).
   - `npm run build` (сборка фронтенда).
