# Навык: Feature Tracker для PeekIt

Данный навык обеспечивает прозрачное проектирование, регистрацию и хронологическое протоколирование любого нового функционала в директории `features/`.

## Структура папки `features/`:
- `features/featurelist.md` — сводный реестр всех запланированных и реализованных фич, их спецификации, приоритеты и статусы.
- `features/worklog.md` — оперативный хронологический журнал работы над функционалом в реальном времени.
- `features/*_plan.md` — проектная документация, схемы архитектуры и планы внедрения.

## Процедура регистрации новой фичи:

1. **В `features/featurelist.md`:**
   - Присвоить следующий свободный ID: `FEAT-XXX`.
   - Добавить запись в таблицу «Сводная таблица функционала»:
     ```markdown
     | **[FEAT-XXX](#feat-xxx)** | Категория | Краткое название | Приоритет | Статус | Версия | [План](ссылка) |
     ```
   - Добавить подраздел с описанием требований и архитектурных решений.

2. **В `features/worklog.md`:**
   - Добавить стартовую запись:
     ```markdown
     #### [YYYY-MM-DD HH:MM] • [FEAT-XXX] • [Проектирование / Разработка]
     - **Цель:** ...
     - **Выполненные действия:** ...
     - **Статус:** In Progress
     ```

3. **В ходе работы:**
   - Фиксировать ключевые этапы (добавление бэкенд-команд, верстка интерфейса, связывание событий, тесты).

4. **При завершении:**
   - Проверить типы (`npm run check`) и компиляцию (`cargo check`).
   - Перевести статус в `features/featurelist.md` в `Completed`.
   - Добавить итоговую запись в `features/worklog.md` и внести строку в таблицу хронологии.
