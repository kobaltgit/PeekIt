# Навык: Bug Tracker для PeekIt

Этот навык обеспечивает поддержание папки `bugs/` в актуальном состоянии в реальном времени.

## Структура папки `bugs/`:
- `bugs/buglist.md` — реестр всех обнаруженных дефектов, их детальное описание, статусы и история.
- `bugs/worklog.md` — оперативный журнал работы в реальном времени с точными метками времени.
- `bugs/*_plan.md` — планы реализации задач и исправлений.

## Процедура регистрации бага (Шаблон):

1. **В `bugs/buglist.md`**:
   Добавить строку в таблицу:
   ```markdown
   | **[BUG-XXX](#bug-xxx)** | Bug | Краткое название | High/Med/Low | Open/In Progress | vX.X.X | [План](ссылка) |
   ```

2. **В `bugs/worklog.md`**:
   Добавить запись:
   ```markdown
   #### [YYYY-MM-DD HH:MM] • [BUG-XXX] • [Диагностика]
   - **Цель:** ...
   - **Симптомы:** ...
   - **Статус:** Open / In Progress
   ```
